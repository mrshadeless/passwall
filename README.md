# passwall2
Passwall2 Installation

Run this command in openwrt remote ssh
```
rm -f freedom-passwall2.sh && wget https://github.com/mrshadeless/passwall/raw/main/freedom-passwall2.sh && chmod 777 freedom-passwall2.sh && sh freedom-passwall2.sh
```
Done !

# passwall Rules
Passwall Rules Creation Separately (Not necessary if you use Passwall Installation)

Run this command in openwrt remote ssh
```
rm -f freedom-passwall2.sh && wget https://github.com/mrshadeless/passwall/raw/main/freedom-passwall2-rules.sh && chmod 777 freedom-passwall2-rules.sh && sh freedom-passwall2-rules.sh
```
Done !
